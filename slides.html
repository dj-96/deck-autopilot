The problem: recurring decks eat junior time

Every month, the most junior consultant rebuilds the same client deck by hand:

  1. Export the new data
  2. Recompute comparisons in Excel
  3. Paste into charts
  4. Rewrite every title whose story changed
  5. Re-check every number: one wrong figure in front of a client costs credibility

From my own strategy-consulting work: general, recurring information, the same manual effort every cycle, and engagements that stop at advice because ongoing reporting is too expensive to keep up.

~3 hper refresh, including checks
~30 hper consultant per month (10 refreshes)

How it works: AI decides, code proves

Analyst agent
Calls 7 Python tools; every number becomes a fact with an ID. Never does math.
Storyliner agent
Writes action titles and bullets that must cite fact IDs. Charts hold only IDs.
Fact-checker
Matches every written number to its fact at the precision written; sends misses back.

Model: gpt-6-luna for both agents (course key; automatic fallback to an OpenAI key). Fixed pipeline = predictable cost, every step testable.
